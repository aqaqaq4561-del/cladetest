## 에이전트 계층 및 모델

| 레이어 | 에이전트 | 모델 | 역할 |
|--------|---------|------|------|
| L0 | 팀리더 | `claude-opus-4-6` + adaptive thinking | 전체 오케스트레이션, 제안서/최종보고 |
| L1 | 팀원 × 4 | `claude-sonnet-4-6` | 심부름꾼 조율, 토론, 보고서 |
| L2 | 심부름꾼 × 최대 32 | `claude-haiku-4-5` | 단위 리서치/구현 |

## 파일 구조

```
multi_agent_system/
├── main.py                    # 진입점 (사용자 인터페이스)
├── config.py                  # 모델/파라미터 설정
├── requirements.txt
├── core/
│   ├── bulletin_board.py      # 에이전트 간 공유 메모리 (asyncio-safe)
│   └── client.py              # 공유 Anthropic 비동기 클라이언트
└── agents/
    ├── runner.py              # 심부름꾼 (research_runner, impl_runner)
    ├── research_team.py       # 리서치 팀원 (ResearchMember)
    ├── impl_team.py           # 구현 팀원 (ImplMember)
    └── team_leader.py         # 팀리더 (TeamLeader) — 메인 오케스트레이터
```

## 핵심 설계 원칙

- **asyncio.gather()**: 진정한 병렬 실행 (심부름꾼 최대 32개 동시)
- **BulletinBoard**: asyncio.Lock 보호 공유 메모리로 에이전트 간 실시간 소통
- **2라운드 토론**: Round-1 초기 합성 → Round-2 크로스 리뷰 → 최종 보고서
- **팀 교체**: Phase 2에서 완전히 새 BulletinBoard + 새 팀원 인스턴스 생성
- **비용 최적화**: L0(Opus) → L1(Sonnet) → L2(Haiku) 계층별 모델 선택
